# StatusDurations

StatusDurations is a small BetterDiscord plugin that replaces Discord's five standard timed-status choices with your own five durations. It only changes your status and restores the previous status when the selected duration ends.

Configure the five choices from the plugin settings.

## Compatibility

StatusDurations uses BetterDiscord's public API to locate Discord's current-user status settings. Discord's internal modules and status-menu markup can change without notice. If status updates or menu replacement stop working after a Discord update, open an issue with the Discord and BetterDiscord versions and a description of the failing interaction.
